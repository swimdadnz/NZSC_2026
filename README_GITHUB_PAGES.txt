NZSC 2026 - GitHub Pages files

Upload the CONTENTS of this folder to the root of your GitHub Pages repository:

index.html
assets/nss-team-nzsc-2026.png
NZSC_2026_meet_editorial_summary_final.html
NZSC_2026_Day1_editorial_report_PB_corrected.html
NZSC_2026_Day2_editorial_report_PB_corrected.html
NZSC_2026_Day3_editorial_report_PB_corrected.html
NZSC_2026_Day4_editorial_final.html
NZSC_2026_Day5_editorial_final_v2.html

The index page links to the reports using relative URLs, so keep these filenames unchanged and place the report HTML files in the same directory as index.html.

GitHub Pages setup:
1. Create/open the repository and upload these files/folders.
2. In GitHub: Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select your publishing branch (normally main) and /(root), then Save.
5. GitHub will display the published Pages URL when deployment completes.

The landing page uses the supplied team photo locally and currently loads the NSS logo and one supplementary About-page image directly from static.wixstatic.com. If you later want the site to have zero external image dependencies, download those two images into assets/ and change their URLs in index.html to relative asset paths.
